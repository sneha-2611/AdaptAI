# AdaptAI – Personalised AI Tutor for Learning AI

## 💡 Project Overview

AdaptAI is an AI-powered personalised learning platform designed to help students learn Artificial Intelligence and Machine Learning according to their knowledge level and learning progress.

It aims to identify learners' strengths and weaknesses, provide personalised learning recommendations, offer AI-powered explanations, and support adaptive practice.

### Core Workflow

Assess → Analyse → Personalise → Learn → Practice → Adapt → Track

## 🎯 Why AdaptAI?

Every learner has a different level of understanding and learning speed. Traditional learning approaches often provide the same content and difficulty to everyone.

AdaptAI aims to make learning more personalised by identifying knowledge gaps and adapting learning recommendations based on individual performance.

## ✨ Key Features

* Knowledge Assessment
* Knowledge Gap Identification
* Personalised Learning Path
* AI Tutor
* Adaptive Quiz Engine
* Progress Dashboard
* Learning Recommendations
